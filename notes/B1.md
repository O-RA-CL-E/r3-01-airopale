# B1 — L'API à la main

## Météo
- Sous quelle clé sont les valeurs du moment ?
  > Sous `current` (avec `time`, `temperature_2m`, `wind_speed_10m`, `weather_code`).
  > Les unités sont dans `current_units`.
- Température à Calais / `weather_code` / signification (CodeMeteo.php) :
  > À compléter avec les valeurs du navigateur, ex. : 9.4 °C, code 3 → « Couvert ».
  > (0 Ciel dégagé, 1 Plutôt dégagé, 2 Partiellement nuageux, 3 Couvert, 45 Brouillard,
  >  61/63/65 Pluie faible/Pluie/Pluie forte, 80/81/82 Averses…)
- Avec Lille (50.6292, 3.0573) : la température change-t-elle ?
  > Oui (normalement) : l'API calcule les valeurs pour le point demandé. Noter les deux valeurs.

## Qualité de l'air
- `european_aqi` :
  > À compléter (valeur de `current.european_aqi`).
- PM2.5 :
  > À compléter (valeur de `current.pm2_5`, en µg/m³).
