# A1 — Démarrer AirOpale

- Quel est l'hôte de la base (`DATABASE_URL`) ? Pourquoi pas `localhost` ?
  > L'hôte est `db`, le nom du service MySQL dans `docker-compose.yml`. Symfony tourne DANS
  > le conteneur `web`, pour lui `localhost` désigne le conteneur web lui-même, où il n'y a
  > pas de MySQL. Docker fournit un DNS interne qui résout `db` vers le conteneur de la base.
  > Le port est 3306 (port interne) et le port 13306 n'est que la redirection vers ma machine Windows.

- À quoi serviront `METEO_URL` et `AIR_URL` ?
  > Ce sont les adresses de base des deux API Open-Meteo : la météo (api.open-meteo.com) et la
  > qualité de l'air (air-quality-api.open-meteo.com). Le service ClientMeteo les lira pour
  > construire ses requêtes. Comme elles sont en configuration et pas dans le code, on peut
  > basculer sur la fausse API (`.env.local`) sans modifier une ligne de PHP.
