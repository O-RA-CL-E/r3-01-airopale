# A4 — La liste des villes

- Requête SQL vue dans le profiler :
```sql
SELECT t0.id AS id_1, t0.nom AS nom_2, t0.latitude AS latitude_3, t0.longitude AS longitude_4 FROM ville t0 ORDER BY t0.nom ASC
```
- Qu'est-ce que le `t0` ?
  > Un alias de table généré par Doctrine pour `ville` (« table n°0 »). S'il y avait des
  > jointures, les autres tables seraient t1, t2… : chaque colonne est préfixée sans ambiguïté.
